### Why this file and not `mujoco_menagerie`

This XML is **self-contained**: every collision and visual shape is a primitive geom
(capsules, spheres, an infinite plane) and both textures are procedurally generated by
MuJoCo's compiler from the `<asset>` block. There is no `<mesh>` element, no `file=`
attribute and no `<include>` anywhere in it, so nothing else has to be downloaded for it to
compile. That is what keeps this lesson inside the `cpu8` budget and lets it run with no
network at all. The `mujoco_menagerie` humanoids ship megabytes of STL meshes per model and
are deliberately out of scope here.

### Offline guarantee

`lesson.py` resolves this cached file through `humanoid_xml_path()`, which searches the
lesson directory and its parent before ever considering the network. The download branch
exists only for a checkout where `assets/` was not fetched; on a normal run — including the
execution gate — no request is made. Nothing in the lesson requires connectivity.
